# Application Strategy: PPRO Staff Frontend Engineer

## Role Details
- **Company:** PPRO
- **Role:** Staff Frontend Engineer (Transaction Processing)
- **Location:** Munich, Germany (Hybrid - 3 days onsite)
- **Core Requirements:** React, TypeScript, Micro Frontend Architecture (Module Federation, Webpack/Vite), CI/CD, AWS/Docker/Kubernetes.

## Strategy Used
1. **Focus on Frontend Architecture:** Shifted the focus from backend/embedded systems to pure, high-level frontend architecture. Emphasized scaling frontends, shared component libraries, and decoupling UIs.
2. **Micro Frontends & Module Federation:** Positioned the Lupply ecosystem (SaaS dashboard, marketplace, admin panel) as a distributed frontend ecosystem where UIs are deployed independently but share core components and contracts.
3. **Staff Level Mindset:** Elevated the language to reflect a "Staff" level—talking about DX (Developer Experience), setting technical standards, establishing CI/CD deployment pipelines, and leading cross-functional teams.
4. **Cloud & Delivery:** Highlighted Kubernetes, Docker, and Fastlane/GitHub Actions from Lupply to show deep understanding of how federated frontends are actually built and deployed to production.

- `ppro_cover_letter.html`: Cover letter addressing the micro frontend challenges and Staff-level impact.
