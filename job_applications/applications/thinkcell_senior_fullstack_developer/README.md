- **Company:** think-cell

- **Core Requirements:** Full stack web (HTML, CSS, JS), PHP/Laravel or similar, CMS/publishing workflows, architectural ownership, Core Web Vitals, SEO, C++ backend integration.

## Strategy Used

1. **Reframed as "Web Platform Engineer":** The Wolt resume positioned Collins as a Backend/Platform/Infrastructure engineer. This resume is entirely reframed around web platform development — frontend + backend across the full web stack, with CMS and content operations front and center.

2. **C/C++ as the Killer Differentiator:** The JD explicitly mentions "Interface with back-end systems written in C++." Almost no web developer can claim real C/C++ experience. Collins has years of it from NodeX iHub (ESP32, FreeRTOS, MQTT/TLS). This is positioned as a rare advantage in both the resume summary and the cover letter.

3. **PHP/Laravel Gap — Addressed Head-On:** Collins has no PHP experience. Rather than hiding this, the cover letter addresses it directly with honesty, then reframes it: "I've picked up Go, Rust, Python, and multiple JS frameworks on the job. Learning a new backend framework within an existing codebase is something I've done repeatedly." This turns a gap into a demonstration of adaptability.

4. **CMS/Content Operations Thread:** Lupply's admin dashboard, Shuri Education's content platform, and NodeX's EdTech platform are all reframed as CMS/publishing workflow experience — exactly what think-cell needs.

5. **Performance & SEO Proof:** Lunar Finance (350k+ users, latency optimization) and Lupply (Core Web Vitals, structured data, image pipeline optimization) demonstrate real performance engineering on web platforms.

6. **Tailwind CSS & Nice-to-Haves:** Explicitly mentioned in the skills section since it's in the JD's "Nice to have" list. Alpine.js listed as "familiar."

7. **EU Visa Bypass:** Same approach as Wolt — explicit mention of Corporate Affairs Commission documentation proving 4+ years, satisfying German IT Specialist Visa requirements.
