# Application Strategy: Hedge Your Fun (Superteam Earn)

## Role Details
- **Company:** Hedge Your Fun (via Superteam Earn)
- **Role:** Full Stack Solana Developer for Production MVP
- **Compensation:** $24,000 USDC/year (Remote/Bounty)
- **Core Requirements:** Next.js, TypeScript, Node.js, Solana Web3.js, SPL tokens, Prediction market APIs (Kalshi/Polymarket), Privy embedded wallets, PWA/React Native.

## Strategy Used
1. **Focus on Web3 & Solana:** Shifted the focus entirely away from traditional enterprise apps to Lunar Finance, Solvux, and Kitty Couture. These prove deep Solana ecosystem knowledge (Jupiter API, Rust, Web3.js, SPL tokens).
2. **Address Privy & Kalshi/Polymarket:** Emphasized ability to quickly integrate 3rd party APIs and handle on-chain settlement, highlighting past DEX aggregator experience which is very similar to routing prediction markets.
3. **PWA/Mobile Readiness:** Highlighted the Lupply ecosystem (Web, iOS, Android via Fastlane) to prove capability in taking the web app to mobile distribution.
4. **Agentic Coding as an MVP Accelerator:** Positioned Collins' use of AI agents as a massive advantage for an MVP that needs to go to production fast.

## Deliverables
- `proposal.txt`: The text to paste into the application form's cover letter/pitch section.
- `hedge_your_fun_resume.html`: A tailored resume prioritizing Solana, Web3, and Full Stack MVP shipping.
