# Application Strategy: Wolt Senior Software Engineer

## Role Details
- **Company:** Wolt
- **Role:** Senior Software Engineer (Data Developer Experience)
- **Location:** Helsinki, Finland / Berlin, Germany
- **Core Requirements:** Large-scale distributed systems, Go/Python, CI/CD, Agentic Coding, Data platforms.

## Strategy Used
1. **Agentic Coding Highlight:** Emphasized the "Agentic Coding workflow" in both the resume summary and the cover letter. This is a unique keyword from their JD that sets this application apart.
2. **Polyglot Mindset:** Positioned Collins as a language-agnostic engineer (Go, Rust, Node, Python, C++) capable of picking the right tool for the job.
3. **Infrastructure & DX:** Heavily highlighted solo-deployment of Lupply using Fastlane, GitHub Actions, and Kubernetes/Docker. The JD is for a "Developer Experience" team, so showing empathy for DX and platform operations is crucial.
4. **EU Visa Bypass:** Addressed the "Education" section on the resume and the final paragraph in the cover letter explicitly stating that the official corporate documentation proves the 4+ years required to bypass degree requirements for the EU Specialist Visa.
